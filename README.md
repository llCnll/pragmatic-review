# pragmatic-review

面向 AI coding agent 的务实代码审查 Skill，优先指出有证据、值得在变更合入前修复的问题。

## 使用

直接说明审查范围和关注方向，例如：

- 审查当前未提交改动
- 只审查暂存区，并关注后端可靠性
- 按架构方向审查指定变更范围
- 做一次 deep review

范围与方向可以分别指定或组合；只指定方向时，默认审查当前未提交改动。

## 关注点

可维护性、认知复杂度、未来缺陷与调试成本、重要失败路径、外部副作用和架构边界；对照已确认契约与代码行为，并检查高风险变更的验证证据。

## 结构

- SKILL.md：入口和模块路由
- prompts/core：评审立场、范围、优先级和输出约定
- prompts/routing：根据变更选择评审模块
- prompts/modules：通用评审关注点
- prompts/specializations：前端、后端、可靠性、架构和性能方向
- agents/openai.yaml：Codex 界面元数据

## 扩展原则

扩展时按问题类型增加模块、按领域补充专项。新增模块应有明确触发条件和证据标准；优先组合现有能力。
