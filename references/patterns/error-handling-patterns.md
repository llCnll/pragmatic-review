# 错误处理

适用于接口、业务用例、数据访问和外部依赖的失败处理。

## 分类与传播

区分参数错误、业务拒绝、资源缺失、依赖失败和系统异常。对外返回稳定错误码、字段路径、提示和恢复方式；内部诊断保存根因、关联上下文和项目允许的脱敏信息。

错误转换保留字段路径、业务码与可恢复性。依赖失败沿相应失败状态处理，接口文档、测试和调用方使用同一错误语义。

例如：参数错误定位字段，资源缺失返回资源错误码，依赖超时按已确认恢复语义处理。

## 异步重试与恢复

适用于任务调度重放当前任务或执行轮次的场景。

- 同步请求、预检和查询沿同步边界处理错误，异步任务明确可重试的读写能力。
- 匹配规则以具体接口契约或实际证据为依据，区分可恢复错误和其他错误分支。
- 重试由一个层级拥有。调度器负责重放时，节点向调度器传递决定，明确尝试上限与退避。
- 重放前核对远端结果。具有重复写入风险的结果待核实时，先核验或进入未知状态，再按事实恢复。
- 每次实际调用单独审计，复用成功检查点，按租约规则释放或续租执行权。

具体能力、错误码和消息条件归所属项目契约维护。异步恢复为试用中模式，跨任务及重复写入场景按证据验证。

## 最小验证

覆盖正常、输入错误、业务拒绝、依赖异常及意外异常，核对 HTTP／业务码、字段路径、日志和调用方处理。

异步任务补充规则命中及其他错误分支、同步边界、尝试上限、退避、调度重放、成功结果复用、审计和租约。写入结果待核实时验证远端核验或未知状态处理。

## 来源与状态

来源：异步外部调用失败后的调度重试实践。状态：试用中；已在一个异步任务场景验证，需在其他任务类型中复用并验证重复写入风险的恢复语义后再评估升级。
