# 查询与数据访问

适用于列表、详情、过滤、排序、分页和组合条件。

## 查询契约

优先使用项目已有 Query DSL、查询构造器或 ORM。结构化条件统一承接空值、默认值、分页与排序，服务端允许集合决定可查询字段和排序能力。

简单查询沿现有入口表达，抽象用于实际复用与变化。复杂查询结合索引、数据量、性能及权限评估。

SQL 作为当前查询能力需要的选项，值按参数绑定，动态标识符按受控映射生成；具体规则见[SQL 安全](sql-safety-patterns.md)。

例如：sort=name:asc 解析为允许集合中的 name 与 ASC，再交给查询构造器。

## 最小验证

覆盖正常条件、空条件、空结果、分页边界、非法排序字段、大数据量和权限隔离。核对真实查询能力、当前范围和稳定排序。
