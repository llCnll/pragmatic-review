# SQL 安全

适用于手写 SQL、动态条件、排序、字段或数据源选择。

## 值与标识符

SQL 值使用驱动或 ORM 的参数绑定；表名、列名和排序方向由服务端白名单映射生成。输入作为绑定值处理，SQL 结构由受控语句维护。

例如：keyword 通过真实绑定参数传递，排序字段映射为允许的列名和方向。

参数 API 和标识符能力核对当前驱动、ORM 及数据库的一手资料。

## 最小验证

使用引号、注释符、通配符和恶意片段核对参数化结果：输入作为绑定值处理，执行结构与权限范围保持。核对实际参数 API、生成语句和结果。

## 来源与状态

来源：安全底线与数据库官方参数化实践。状态：已验证。
