# 组合根与能力登记

适用于 Runtime 按部署配置装配 Provider、Adapter、Writer、Registry、处理器或观测组件。

## 能力与装配

Runtime 集中选择配置和创建依赖。每项能力声明端口、登记名称、方法集合与能力校验；启用能力、注册表和部署配置同步维护。

根据启用能力计算必要依赖，缺项返回明确配置错误。只读模式装配读取能力，真实写入模式装配实际可调用的写入能力。静态注册表保存能力声明，请求凭据、载荷和任务快照由运行上下文持有。

简单 Service 可直接装配，组合容器服务实际依赖变化。就绪状态对应真实实现与资源事实。

## 最小验证

核对注册表与 Runtime 的启用能力，覆盖读取和写入配置的装配检查。执行对应框架的启动或健康检查，并在生产流量前完成只读冒烟。

成功标准：启用能力在真实执行前通过最小方法与依赖检查；缺项按稳定配置错误处理。

## 来源与状态

来源：业务 Runtime 能力登记遗漏的修复复盘。状态：试用中；当前项目已验证，尚需跨项目复用验证。
