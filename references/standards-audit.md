# 开发规范统计

适用于规范核对、问题类别、举例或数量统计。范围按用户指定的 diff 或代码集合，报告覆盖与粒度按用户需要。

## 依据与性质

读取仓库适用规范的完整相关小节、前提与例外，核对检查配置和已确认契约，再结合通用质量判断评估代码。每项发现注明性质：

| 性质 | 依据 |
| --- | --- |
| 明确规范违例 | 可以定位的适用规则、检查配置及违反证据 |
| 维护性风险 | 代码结构、依赖或重复产生的具体当前成本或演进风险 |
| 功能缺陷 | 可观察行为与已确认契约之间的差异 |
| 待核对 | 需要补齐的规则、证据或目标环境 |

仓库强制规则沿其确认依据判定，默认做法、建议和项目例外按各自性质使用。严重度依据实际影响，问题类别依据性质，二者分别表达。分支、字面量、Mixin 和转换代码的评估结合职责、行为与维护成本。

## 分类与举例

按实际发现归类，以下线索用于定位证据：

| 类别 | 核对线索 |
| --- | --- |
| 分支复杂与职责混杂 | 多种决策交织、隐藏顺序、重复模式判断、多类副作用混在同一方法 |
| 硬编码与声明分散 | 同一业务集合、默认值或边界多处维护，核对原值语义与维护源 |
| 重复规则与映射 | 同一规则多套实现、字段映射易漏同步，核对各协议边界的独立职责 |
| 拆分与隐式依赖 | 拆文件后仍需共享隐藏状态，追踪依赖方向和事实所有者 |
| 类型与契约边界 | 核对稳定结构、动态探测和契约，以及缺失与空值的语义 |
| 错误与可观测性 | 核对错误分类、传播、日志责任和根因关联 |
| 基础格式与静态检查 | 核对本次范围的类型写法、导入和格式与项目配置 |
| 其他项目专项 | 数据库、查询、权限、兼容或任务规范等实际命中的约束 |

概览提供“类别、表现、举例”；完整核对可增加依据、性质、数量／范围和处理方向。规范统计覆盖用户指定类别及项目明确要求，包括常规格式和类型规则。

## 计数与范围

数量结论对应实际测量，说明统计单位、文件／diff 范围及快照。区分类别数、位置数、受影响文件数和独立问题数；同一根因按一个主类别累计。样例用于举例，完整数量由完整统计支持。

工作区评审将存量问题与新增／修改行分开。全文件 lint 结果先对应到本次差异。施工内容注明观察状态，缺陷结论由已形成的行为与验收差异支持。

计数待补齐或代码并发变化时，标为未逐项计数或限定观察快照。
