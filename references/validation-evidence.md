# 风险与验证证据

本文件维护通用技术验证判断，供实施自检、诊断、评审和规范统计按需使用。项目验收、目标环境和已确认风险约束优先；实际调用与副作用沿各自授权执行。

## 风险判断

| 风险 | 依据与验证投入 |
| --- | --- |
| 低 | 局部变化且行为边界清楚，采用相关静态检查或业务用例 |
| 中 | 业务规则、查询、接口或数据处理变化，覆盖正常、失败和边界结果 |
| 高 | 权限、资金、迁移、并发、关键状态、敏感数据、共享设施、外部副作用或恢复受限的操作，验证状态边界、失败恢复及目标环境语义 |

级别依据影响范围、失败代价和可验证性确定。重构按真实触及的状态、兼容和副作用判断风险。

## 关键能力与最小证据

按当前能力选择对应验证，明确方法、环境、可观察预期和实际结果。

| 能力 | 最小验证与预期 |
| --- | --- |
| 权限与数据范围 | 覆盖允许、权限校验失败和范围外对象；动作、可见性、关系及状态分别生效 |
| 数据迁移 | 对应 alias 和版本的隔离环境执行预检查、迁移与结果核对，确认结构、约束、索引、项目要求的备注和数据；恢复方式对应备份与实际写入状态 |
| 并发与关键状态 | 独立连接制造竞争，合法状态成功，失败按事务边界回滚；核对唯一身份、锁序和旧版本或旧租约的失效处理 |
| 批量写入 | 覆盖全量成功、部分成功或整体回滚，核对项目已确认的事务和汇总边界 |
| 共享设施 | 真实依赖或等价目标环境验证多实例竞争、恢复、取消和幂等，明确共享数据与文件所有权 |
| 外部副作用 | 获准环境验证成功、失败、超时和结果待核实的恢复；核对实际协议、成功检查点复用与持久化结果 |
| 兼容与发布 | 覆盖完整新数据、历史缺字段、空值和旧调用；核对扩展、回填、切换、收缩及实际回滚或人工恢复 |

过滤、剔除与映射验证到最终业务结果。数据库、消息、文件和远端状态分别核对一致性与恢复，执行后的最终持久化或远端事实承接完成结论。

## 环境与证据边界

- Mock 和测试替身验证应用决策、契约及调用编排。
- SQLite 验证其实际支持的业务断言；目标数据库的 DDL、索引、锁和跨连接行为在对应环境验证。
- 缓存、队列和其他共享设施的竞争及恢复由具备这些语义的环境支持。
- 外部 HTTP 同时核对业务最终载荷、实际发送的协议字段及远端结果。
- 性能验证使用可比较场景，记录正确性、资源消耗、次数和波动。

## 完成判断

每项结论关联适用规则、实现路径、状态边界、方法和环境、预期及实际证据。场景状态对应自己的执行结果，问题修复包含复现、修复和回归。

通过、失败、跳过、未执行和环境待匹配分别记录，标明覆盖范围及后续方式。已接受风险保留确认依据，实际生产绑定和等价验证分别描述。

验证记录可引用已有任务、测试或操作证据，观测和审计保持业务结果，并使用项目允许的脱敏信息。
